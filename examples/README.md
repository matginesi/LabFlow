# LabFlow examples

The examples are retained because they serve two concrete validation jobs rather than acting as miscellaneous sample content.

## Complete project package

`example-complete-project.zip` is generated by the same local exporters used in LabFlow. `project-export/` keeps that package unpacked so reviewers can inspect its structure without first navigating the application. The unpacked fixture also includes two small illustrative source files used only for provenance review.

The generated ZIP contains:

- project metadata with Matteo Ginesi as illustrative owner;
- measurement data in JSONL and CSV;
- a six-page palette-aware PDF report with native fillable identity, narrative, approval and measurement fields;
- a native editable DOCX report with structured content controls, headings, complete result tables and provenance;
- an XLSX analysis workbook with ten named sheets, highlighted inputs and recalculating formulas;
- linked knowledge and evidence references;
- a NOMAD mapping preview and validation note;

The supplementary `source/` directory is deliberately outside the generated ZIP contract. It contains a short JV extract and process metadata fixture; neither file is presented as the complete measurement series.

These artifacts are fixtures, not authoritative scientific records. Regenerate and inspect them whenever report, workbook, package or provenance contracts change.

## Standalone theme integration

`theme-integration.html` and its companion stylesheet demonstrate the portable theme package independently from the LabFlow application shell. The page uses only checked-in assets, makes no automatic request and stores no selection after reload.

The example should verify root theme, palette and density controls, local typography, semantic status colors, focus visibility and both light and dark content variants.

## Review expectations

Open the PDF visually and edit at least one narrative and one measurement field. Confirm that the chart is explicitly an export-time snapshot. Update the DOCX table of contents and edit a highlighted content control. Recalculate all workbook sheets, check the input/formula legend and inspect the ZIP manifest. Confirm stable identifiers, provenance, statement classes, author name and the absence of credentials or external resources.
