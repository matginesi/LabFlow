Terminal timer contract. Elapsed time advances only while the Action is running. Completion and final failure freeze one duration. Successful checkpoints continue automatically. Retryable AI failures retry the same checkpoint/work unit after 5 s and 10 s; a normal final failure exposes Retry checkpoint. Design inference is the deliberate exception: its single persistent Retry inference control lives in the selected experiment strip. Stop remains available while work is running.
Fresh-session contract. Opening an Action clears every title, fact, checkpoint, payload, progress class and disclosure inherited from the preceding Action. Provider and Action-contract errors stay in this totem; the Logs page retains their durable diagnostic history without duplicating an error card on the workflow page. An HTTP 200 with empty, truncated, malformed, or contract-invalid model output is shown there as a correlated Rejected response, never as a completed call.

Boundary. Notices remain inline page content. Message Totems are transient feedback or confirmations. Action Totems alone own Action progress, execution details and results.
Assistant theme contract. Chat, badges, notices, code and structured output all inherit the Assistant palette. No light slabs inside dark Assistant chrome and no dark islands in the light theme.
Assistant chat. Questions stay inline; read-tool activity may appear as compact status/telemetry, while internal planner JSON never appears as thinking.
User control. A running Action can be stopped. Normal Action failures may resume from Retry checkpoint; Design inference keeps its one retry control on the selected experiment instead of duplicating it in the totem.
Prompt-first. Every Action has one JSON definition; Actions with AI steps additionally use one action-local Markdown prompt. Settings edits the same runtime Action definition used everywhere; overrides can be reset to source.
Direct provider connection. Hosted providers use their configured official endpoint directly from the browser. Browser CORS/network blocks are reported explicitly.
Provider diagnostics. DevTools exposes LabFlow.AIConsole; the terminal probe python tools/ai_probe.py … bypasses browser CORS to test keys, catalogues and exact model IDs.
AI proposes; code applies. Structured corrections, selected-experiment design inference and NOMAD staging are reviewable proposals. Scientific meaning is never changed silently.
