# LabFlow Design Knowledge Base

This directory is the versioned, folder-backed Design Knowledge Base.

Open **Knowledge Base** in LabFlow, choose this directory, and grant read/write access. LabFlow manages `library.json` directly from the browser. Records remain separate from the experiment Working Copy and enter Design only through the explicit fill-only Apply operation.

`library.json` uses schema version `1` and contains reusable `material`, `solution`, `process`, and `stack` records. The starter records are transcribed from the primary literature cited in each record's `sources` array. They are reusable references, not evidence that a value belongs to the currently imported experiment; review and adapt them before explicitly applying them.
