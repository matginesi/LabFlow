# LabFlow workflow

The canonical researcher path is:

`Workspace → Experiment → Resources → Stacks → Data → Analysis → Outputs → Export`

Projects group related experiments. The Lab Cabinet holds shared definitions;
an experiment stores explicit usage snapshots so later Cabinet edits cannot
silently change historical work.

Canonical entry points are Workspace, Experiment, Lab Cabinet, Imports, Tools,
Report & Export Center and AI workspace. The POC uses progressive disclosure:
small records use small forms; longer scientific work uses resumable stages
with visible context, review and warnings.
