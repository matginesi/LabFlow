# Glossary

- **Lab Cabinet**: shared reusable laboratory definitions and availability.
- **Usage snapshot**: experiment-owned record of how a resource was used.
- **Evidence**: records, files, columns or metrics supporting an output.
- **Provenance**: source, transformation, author and decision trace.
- **AI output**: separate draft generated from an evidence bundle.
- **Controlled agent**: bounded workflow behind approval gates.
- **Semantic search**: simulated retrieval with sources and reasons.
