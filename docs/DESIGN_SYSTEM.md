# Design system

LabFlow uses compact technical surfaces, low radii, restrained navy/blue/teal
accents and information-bearing borders. One primary action leads each view.
Secondary and advanced actions remain visually quieter.

The UI Kit is the canonical component showcase. Product pages and examples share
the same classes for panels, buttons, forms, tables, states, drawers, Lab
Cabinet records, Tools, exports, AI evidence and approval controls.
