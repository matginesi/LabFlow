# Glossary

**FW** — Forward voltage scan.  
**RV** — Reverse voltage scan.  
**Voc** — Open-circuit voltage.  
**Jsc** — Short-circuit current density.  
**FF** — Fill factor.  
**Efficiency / PCE** — Power conversion efficiency.  
**MPP** — Maximum power point.  
**MPPT** — Maximum power point tracking.  
**Hysteresis** — Difference between FW and RV behavior; LabFlow stores the deterministic calculation and flags large magnitude values.  
**REF** — Reference/control sample designation when indicated by source naming/metadata.  
**RAW** — Original immutable laboratory files.  
**Patch** — Non-destructive correction to LabFlow's interpretation.  
**Finding** — Data-quality or interpretation issue requiring attention.  
**Provenance** — Origin/status of a value or decision.
